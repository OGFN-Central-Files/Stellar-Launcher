3. Inicio de sesión (backend externo + deep link)
Flujo OAuth por deep link stellar://, sin formularios:

Descubrimiento de rutas: src/zustand/RoutingStore.tsx → initRouting() hace GET https://prod-api-v1.stellarfn.dev/stellar/launcher/v1/routing?type=<tipo> para los tipos auth, public, account, oauth, leaderboards, tournaments, rewards. Cada tipo devuelve { url } y se cachea en localStorage (stellar:routing.store). Todas las URLs del backend son dinámicas (el launcher no hardcodea endpoints salvo el de routing y los CDN).
src/pages/Login.tsx — botón "Continue" ("Connect your Discord account") → open(authRoute.url) (navegador del sistema, plugin-shell). Pantalla splash "Welcome to Stellar" de 2.4 s; si hay JWT válido en storage navega a /home.
El backend web devuelve stellar://<JWT> → onOpenUrl (plugin-deep-link, esquema registrado en tauri.conf.json) captura la URL, extrae el JWT y llama AuthStore.login(jwt).
src/zustand/AuthStore.tsx → GET <ruta "account"> con Authorization: bearer <jwt> → responde { account: IAccount, athena: IMCPProfile }. IAccount (src/stellar/interfaces/IAccount.ts): AccountID, Email, Password, DisplayName, DiscordID, IsBanned, Roles, Rewards, ProfilePicture....
Auto-update en el login: check() del plugin-updater contra https://cdn.stellarfn.dev/update.json (pubkey minisign, installMode: passive) → downloadAndInstall + relaunch().

Todo en src/utils/library/handlePlay.ts (TS) + src-tauri/src/commands/builds.rs (Rust).

Auth de lanzamiento:
GET <ruta "oauth">/exchange con Authorization: bearer <jwt> → { code } (exchange code).
GET <ruta "account">/session con Authorization: bearer <jwt> y header X-Arc-Client: rokzoyzmxxjqekqdqkipgkdueoybqjqo → { auth: { token } } (identidad para el anticheat Arc).
invoke("launch", { code, path, extraArgs, identity }), minimiza la ventana (window.getCurrentWindow().minimize()) y envía notificación nativa.
Comando Rust launch (src-tauri/src/commands/builds.rs, líneas 135–285)
Borra Engine\Binaries\ThirdParty\NVIDIA\NVaftermath\Win64\GFSDK_Aftermath_Lib.x64.dll (hasta 50 reintentos de 20 ms) y recrea el directorio — elimina el crash reporter de NVIDIA.
No inyecta DLLs: no hay CreateRemoteThread/WriteProcessMemory/LoadLibrary en ningún archivo (las features memoryapi de winapi están declaradas en Cargo.toml pero sin uso). El "anticheat" es un proceso externo (Arc.exe) descargado en el build.
No usa puerto local ni -AUTH_PORT=: el auth es el exchange code oficial de Epic (-AUTH_TYPE=exchangecode), y la sesión la valida Arc mediante -t=<token>.
